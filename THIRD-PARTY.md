## Artwork

`assets/rivage-waterlilies.jpg` is an image generated with an AI image tool for
this project, in an impressionist style, as the editor background. It is not a
reproduction of any particular existing painting, and no third-party image,
scan or photograph was used as its source.

No copyright is claimed over the generated image: it is included under the same
AGPL-3.0-or-later terms as the rest of the project. Some jurisdictions do not
recognise copyright in purely machine-generated images, in which case the file
simply carries no separate rights at all. It is embedded into the binary as
binary data, is decorative only, and can be swapped for any image of the same
name before building.

The social preview image (`docs/social-preview.jpg`) is generated by
`scripts/make_social_preview.py` from the same file plus a screenshot of the
editor.

## Inno Setup messages

`installer/ChineseSimplified.isl` is the Simplified Chinese message file from the
Inno Setup user-contributed translation collection, maintained by Zhenghan Yang
(Kira). It has been trimmed to the message names that Inno Setup 6.2.2 knows, and
it is used only while packaging the Windows installer — it is not part of the
plug-in binary.

with this project.
